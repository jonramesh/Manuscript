Niche HTML Elements

Everything below is real, standard HTML — rendered live, no JavaScript.

Typography & annotation

<ruby> <rt> <rp>

Annotations that ride above the line. Built for Japanese phonetic guides, but nothing stops you glossing vocabulary with it.

The essay turns on network power(Grewal, 2008) and its quieter cousin soft power(Nye, 1990).

The <rp> tags are fallback parentheses for browsers with no ruby support. ruby-position: under flips the annotation below.

<q>

Inline quotation. The browser inserts the quote marks — and picks the right ones for the language.

English: join the brandwagon
French: join the brandwagon
German: join the brandwagon
Japanese: join the brandwagon

You never type a quote character. Override the marks entirely with the CSS quotes property.

<abbr>

An abbreviation, with the expansion in title. Dotted underline by default; hover to read it.

Estonia joined NATO and the EU, while NGOs reshaped what sovereignty meant.

Your essay is full of these. Note the tooltip is mouse-only — don't hide anything essential in it.

<bdi> and <bdo>

<bdi> isolates text whose direction you don't control, so a right-to-left name can't scramble the sentence around it. <bdo> force-flips direction.

Isolated: author محمد — 3 citations
Reversed: This text runs backwards

Essential the moment user-generated names appear in a list. Almost nobody knows it exists.

<wbr>

An invisible "you may break the line here" hint. No hyphen, no space — it only acts if the line actually needs to wrap.

https://example.com/place-branding/network-power/structural-coercion/threshold-of-inevitability

The fix for long URLs and compound words blowing out a narrow column.

<ins> and <del>

Editorial insertions and deletions — and both take cite and datetime attributes recording who changed it and when.

Soft power is entirely allegedly non-coercive.

Different from <s>, which means "no longer accurate" rather than "removed from the document."

<small>, <s>, <u>

All three have real meanings, not just looks. <small> is side-comments and small print. <s> is no-longer-accurate. <u> is a non-textual annotation — its actual spec example is marking a misspelling.

Unipolar Nonpolar world order.
interpersed with Soviet-era footage
Originally published in e-flux journal, 2008.

Avoid <u> for anything else — readers will read it as a broken link.

<time> and <data>

Human-readable text with a machine-readable value attached. <time> for dates, <data> for everything else.

Haass wrote in 2008; Mouffe in 2005.
The essay runs roughly eight thousand words.

Invisible to readers, legible to search engines and scripts.

<var>, <kbd>, <samp>, <code>

Four different kinds of technical text that people usually collapse into one <code>.

Press Cmd + Shift + R to hard-refresh.
Let n be the number of subscribers.
The server replied 404 Not Found.
Set position: sticky on the header.

<kbd> = keys pressed. <samp> = output from a program. <var> = a variable. <code> = source.

Structure

<dl> <dt> <dd>

A description list — term paired with description. This is exactly what your TERMINOLOGY view wants to be.

place brand
A trademark for a place — a nation, region or city.
brandwagon
Van Ham's coinage for the pressure on unbranded nations to adopt a state brand because everyone else has.

One <dt> can have several <dd>s, and vice versa — good for synonyms.

<figure> + <figcaption> + <blockquote>

The spec-correct way to do an attributed pull quote. The attribution isn't part of the quote, so it lives outside the blockquote.

Two different cites here: the attribute holds a source URL, the element marks a work's title.

<hgroup>

Binds a heading to its subtitle so the tagline doesn't pollute the document outline as a separate heading.

Brand States

Postmodern power, democratic pluralism, and design

Exactly your article title situation.

<search>

Added to HTML in 2023 — a landmark for search and filter controls. Most developers have never heard of it.

Maps to the ARIA search landmark for free. Replaces role="search" on a div.

<address>

Contact details for the author of the nearest article or the document — not for postal addresses in general, which is the usual misuse.

Written by Metahaven.
Amsterdam.

Italic by default. Belongs in a footer, or inside the article it describes.

Interactive — with no JavaScript at all

<details> + <summary>

A native disclosure widget. Click to expand. Keyboard accessible, announced correctly, zero script.

What is structural coercion?

Pressure built into an arrangement rather than exercised directly — a formally free choice made where the alternatives have already been removed.

Give several the same name…

…and they behave as an accordion: opening one closes the others. Still no JavaScript.

…like this one

Opening this closed the one above it.

Style the marker with ::marker or summary::-webkit-details-marker. This is the honest answer to most dropdown menus.

<dialog>

A real modal, with focus trapping and Escape-to-close built in. Shown here with the open attribute so it renders inline.

A native dialog. showModal() would centre this over a backdrop you can style with ::backdrop.

The only element that needs JS to be genuinely useful — but it hands you focus management for free.

<meter> and <progress>

Not the same thing. <meter> is a scalar inside a known range — it colours itself green/amber/red against low, high and optimum. <progress> is task completion.

Brand recognition: 20% low

Brand recognition: 90% high

Reading progress: 70%

A <progress> with no value renders as an indeterminate spinner.

<datalist>

Autocomplete suggestions on a plain text input — the user can still type anything. No library required.

Click the field and type "p" — suggestions appear. Perfect for your TERMINOLOGY jump box.

<fieldset> + <legend>

Groups related controls with a caption that visually breaks the border. That notch effect is native and surprisingly hard to reproduce by hand.

Reading mode

Screen readers announce the legend before each control inside it.

Tables & media

<picture> + <source>

Art direction, not just resizing. Serve a genuinely different crop at different widths, or a modern format with a fallback.

Structure only — no image files here:

<picture>
  <source srcset="wide.avif" type="image/avif">
  <source srcset="wide.webp" media="(min-width: 800px)">
  <img src="square.jpg" alt="Tallinn harbour">
</picture>

The browser picks the first <source> it understands and stops. The <img> is required — it's the fallback and it carries the alt.

<map> + <area>

Clickable regions on an image, defined by coordinates. Ancient, still standard, occasionally exactly right — diagrams, floor plans, actual maps.

<img src="baltic.png" usemap="#region" alt="Baltic states">
<map name="region">
  <area shape="circle" coords="120,80,30"
        href="#estonia" alt="Estonia">
</map>

Shapes can be rect, circle or poly. Every area needs an alt.

Odds and ends

<template>

Markup the browser parses but refuses to render. It sits inert in the DOM until a script clones it.

There is a full paragraph inside a <template> directly below this line, and you cannot see it.

Images inside a template don't load and scripts don't run — that's the point.

<noscript>

Content shown only when scripting is unavailable. You'll see nothing here unless you disable JavaScript.

JavaScript is on, so the <noscript> block above is hidden.

Rarely needed now, but still the only declarative way to detect it.

<hr>

Not a line — a thematic break. A scene change in the content. The horizontal rule is just its default styling, and you can restyle it into anything.

Use it where the subject shifts, not where you want a divider. For a divider, use a border.

<output>

A container for the result of a calculation. Announced as a live region, so screen readers read updates aloud automatically.

The live-region behaviour is free — no aria-live needed.

<marquee> deprecated

Scrolling text. Formally obsolete, still implemented by every browser, and genuinely on-brand for an essay about 1990s nation branding.

Don't ship it. The modern equivalent is a CSS @keyframes translation, which you can pause on hover and disable under prefers-reduced-motion.
